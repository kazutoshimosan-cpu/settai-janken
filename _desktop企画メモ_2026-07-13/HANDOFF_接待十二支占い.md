## 0. これは何か（一行）

『限界！接待じゃんけん』の世界観を流用した、**独立した性格診断コンテンツ**。
ユーザーの「接待スタンス」を測り、十二支の12型のどれかで結果を出す。
生まれ干支との「ズレ」を見せるのが主役。

## 1. 企画の経緯（なぜこの形になったか）

判断の軌跡を残す。実装で迷った時はこの「なぜ」に立ち返ること。

### 出発点
- 性格診断アプリを作れないか、という雑談から出発。
- **MBTIは使わない**と決定。理由：日本で「MBTI」は日本MBTI協会の登録商標。無許可の有料利用は商標権侵害リスク（損害賠償・刑事罰の対象）。16Personalitiesすら「MBTI」を名乗らず独自モデルで回避している。→ **診断フォーマットは借りるが、独自の軸・独自の名前でやる**方針。

### なぜ接待じゃんけんと融合したか
- 既存の『接待じゃんけん』がすでにGitHub Pagesでリリース済み（webアプリ）。
- 接待じゃんけんの本質＝「勝ち負け」ではなく「**どう相手を立てるか＝対人スタンス**」。これは性格診断の軸と本質的に噛み合う。
- 抽象的な内向/外向（既存診断の焼き直し）ではなく、**日本の社会人あるある（接待・忖度・同調圧力）という具体で刺す**方が差別化になる。
- 制作者は社会学バックグラウンド。「マクロ/ミクロの視点のズレ」「自己矛盾を抱えた主体」への関心があり、**それを診断ギミックに落とし込む**のが本コンテンツの思想的な核。

### なぜ「別立て」の診断にしたか
- 既存のじゃんけん本編には手を入れない（動いているものを壊さない）。
- 診断は単体で回すほうがSNS拡散の入口として軽い。「診断でバズる→本編へ送客」の導線。
- 十二支という診断母体が既にある（12キャラ、絵・キャラ性が既存資産）。

### なぜ「生まれ干支とのズレ」を主役にしたか
- 日本人は全員自分の干支を持つ → 診断結果の干支とバッティングする問題が発生。
- これを**問題ではなく武器に転換**。「生まれ（本性）」と「接待（処世術）」の二枚看板で対比し、ズレの大きさを煽る。
- 「本性と社会的な顔は違う」＝制作者の関心テーマ（自己矛盾・マクロミクロのズレ）とそのまま接続する。
- にゃん太自身が「猫だから干支に入れない＝規格外」というキャラ。**干支という枠に収まる/収まらないというテーマがIP全体で一貫**する。

### なぜギミックを「振る舞い選択式」にしたか（重要な設計転換）
- 当初はGDDの本編ギミック（正解を当てる勝ち負け型）をそのまま診断に使おうとした。
- **これは誤り**だった。診断で見たいのは「正解できたか（上手い下手）」ではなく「**どう振る舞う人か**」。正誤で軸を動かすと、スキルの差が混ざって性格が濁る。しかもプレイヤーが「勝てるか？」と身構えてしまい、占いの体験として邪魔。
- → **ギミックの見た目（世界観）は借りるが、測り方は「正誤」ではなく「振る舞いの選択」に統一**。同じ場面で正解を探させず、「あなたならどうする？」を選ばせる。全選択肢に正解がない。
- 副次効果：選択式なら1問で2軸同時に動かせるため、少ない設問数でも12型に散る。

### なぜ口調を調整したか
- にゃん太の一人称キャラは残すが、二人称「お前」＋詰問調は初対面の診断相手には感じが悪い。
- → 「あんた」ベースのぞんざいさに落とし、詰問調はやめる。**ぞんざいだが客商売として成立するライン**。

## 2. 確定している設計

### 2-1. 診断の2軸4象限

| 軸 | マイナス方向 | プラス方向 |
|---|---|---|
| **接待の型**（heikou） | 這いつくばり（勝たせる・尽くす） | 場回し（盛り上げる・押して立てる） |
| **接待の心**（dasan） | 打算（頭で動く・計算） | 忠義（心で動く・情） |

象限 → 十二支の割り振り（各3体）：

| 象限 | コード | 十二支 |
|---|---|---|
| 這いつくばり × 打算 | HK-DS | 巳・子・酉 |
| 這いつくばり × 忠義 | HK-CG | 戌・丑・未 |
| 場回し × 打算 | BM-DS | 卯・申・辰 |
| 場回し × 忠義 | BM-CG | 寅・午・亥 |

### 2-2. 12型のキャラ設定

| 干支 | 型名 | 一言 |
|---|---|---|
| 巳 | 完全犯罪型 | 負けたと気づかせず負ける。接待の完全犯罪 |
| 子 | 立ち回り型 | 誰に媚びれば得か一瞬で計算。要領の化身 |
| 酉 | 段取り型 | 負けの手順書を事前に作る几帳面な忖度 |
| 戌 | ど真ん中忠犬型 | 打算ゼロ。ただ相手のために負ける聖人 |
| 丑 | 我慢型 | 何時間でも土下座で耐える鈍行の誠意 |
| 未 | 同調型 | 周りが負けるなら自分も。群れの空気で尽くす |
| 卯 | 愛嬌かわし型 | 可愛げで全部チャラにする天性の人たらし |
| 申 | 機転型 | 笑わせて勝たせる。場を掌握する演出家 |
| 辰 | 大物型 | 接待する側のはずが、なぜか一番偉く見える |
| 寅 | ガチ勝ち型 | 接待のはずが勝ってしまう。負けられない性 |
| 午 | 勢い空回り型 | テンションで押すが方向がズレてる元気印 |
| 亥 | 猪突接待型 | 一途すぎて過剰接待。負けすぎて逆に失礼 |

### 2-3. 隠しレア枠：ネコ（にゃん太）型
- 「規格外型 / そもそも干支に入れない」。
- 両軸ともほぼ0（±7以内）の時だけ出現。通常回答の組み合わせでは基本出ず、**育成で真ん中に寄った時に出る隠し要素**。

### 2-4. 育つ診断値
- 一発診断で終わらせず、再診断時に前回の傾きを一定割合（プロトでは30%）持ち越す。
- 境界付近にいる人は日によって型が入れ替わる。
- 思想的な意味：**タイプは固定ではなく状況で揺れる**＝固定的性格診断へのアンチテーゼ。制作者テーマの体現。

## 3. 判定ロジックの詳細（プロト実装値）

各ギミックは「振る舞いの三択」。選択で `dasan` と `heikou` を加算（clamp -100〜+100）。

### ギミック1：子（ネズミ）の陽動ラッシュ
指示がコロコロ変わる先輩にどう構えるか。

| 選択 | dasan | heikou | 意味 |
|---|---|---|---|
| 止まるまでジッと待つ | -15 | -4 | 打算（冷静） |
| 愛想笑いで合わせにいく | -3 | -15 | 這いつくばり |
| 自分のペースで出す | +6 | +16 | 場回し（マイペース） |

### ギミック2：寅（トラ）の威圧の沈黙
無言の圧にどう出るか。

| 選択 | dasan | heikou | 意味 |
|---|---|---|---|
| 必死に顔色を読む | -4 | -15 | 這いつくばり（察知） |
| 先に下手に出て負けとく | +15 | -6 | 忠義寄りの這いつくばり |
| 話しかけて場を和ませる | -2 | +16 | 場回し |

### ギミック3：申（サル）の猿真似コピー
自分の手を真似される→次どう出るか（自己との対峙）。

| 選択 | dasan | heikou | 意味 |
|---|---|---|---|
| 同じ手を貫く | +16 | +6 | 忠義（ブレない） |
| 裏をかいて変える | -16 | +2 | 打算 |
| 相手に合わせる | -2 | -16 | 這いつくばり |

### 型の決定
```
if (|dasan| <= 7 && |heikou| <= 7) → ネコ（レア）
象限 = (heikou<0 ? HK : BM) + (dasan<0 ? DS : CG)
象限内の絞り込み（sh=|heikou|, sd=|dasan|）:
  sh >= sd*1.6  → idx 0（這い/場の軸が優勢＝象限の代表格）
  sd >= sh*1.6  → idx 2（打算/忠義の軸が優勢＝境界寄り）
  それ以外       → idx 1（拮抗＝中間）
```

### ズレ演出のロジック
- 生まれ干支の象限と接待型の象限を比較。
- 両軸とも異なる（diff=2）→「ズレ、最大」：本性と処世術が正反対。
- 片軸だけ異なる（diff=1）→「ズレ、あり」：半分だけ自分を作り替えている。
- 同じ型 →「ズレ、なし」：裏表のない人。

## 4. 積み残し課題（本実装で対応）

### 診断ロジック
- [ ] **丑・申の2型が出ない**：3問×3択（27通り）では構造的に全12型をカバーできない。対応案は2つ——(A) GDDの残りギミック（ウシ/ヘビ/イヌ等）から数個を診断化して設問を増やす、(B) 象限内絞り込みの網目を再設計。**(A)推奨**（設問が増えるほど精度も上がる）。
- [ ] 各ギミックの加算値は仮。設問追加後に全型が均等に近く出るよう再チューニング。分布検証スクリプトを回して確認すること（プロト時は全組み合わせ総当たりで分布を出した）。

### 永続化・データ
- [ ] 育つ診断値の**永続化**。プロトはReact stateのみ（セッション内で消える）。本番はlocalStorage or バックエンドで診断履歴を保持。
- [ ] 診断履歴から「先月は巳型、最近トラ型に寄ってきた」のような**変化の可視化**。

### 拡散・展開
- [ ] **SNSシェア画像の生成**（結果の二枚看板を画像化）。診断単体で拡散させる入口として最重要。
- [ ] **ウィジェット化**：「今日の一問」を日替わりで出し、答えるたびに診断値が微増。占いの「今日の運勢」的な毎日開く動機。通知連携も検討。
- [ ] 既存『接待じゃんけん』本編への送客リンク。

### 世界観の作り込み
- [ ] 12型それぞれの結果文をもっと厚く（強み/弱み、相性のいい型・悪い型、有名人例など）。
- [ ] キャラ立ち絵（既存の接待じゃんけん資産を流用できるか確認）。

## 5. 世界観・トンマナ（厳守）

- **舞台:** 株式会社・十二支建設（GDD準拠）。干支の動物が牛耳る理不尽な建設会社。
- **語り手:** にゃん太（干支に入れなかった猫社員）が占い師として「見立てる」枠。
- **口調:** 一人称「オレ」。二人称「あんた」。ぞんざいだが客商売として成立するライン。**「お前」・詰問調は禁止**。バカゲーのノリとシュールな笑い。
- **ビジュアル:** 和紙 ＋ 朱肉（朱印）＋ 墨。ゆるキャラ風。結果は**判子（印影）**で出す＝日本の判子文化として世界観的必然性がある。生まれ＝墨印、接待＝朱印で対比。
- **フォント参考:** ディスプレイ = Dela Gothic One（極太）、本文 = Zen Kaku Gothic New。
